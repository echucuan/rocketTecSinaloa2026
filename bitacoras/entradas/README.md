# Entrada de bitácoras

Sube aquí los archivos ZIP originales generados por la página de bitácoras.

- No descomprimas ni vuelvas a comprimir los archivos.
- Puedes subir uno o varios ZIP en el mismo cambio.
- GitHub validará cada paquete y publicará los registros válidos.
- Un ZIP repetido se omitirá sin crear otra publicación.
- Un identificador repetido con contenido diferente será rechazado.

Después de publicar, la automatización retira el ZIP de esta carpeta y conserva una copia en `bitacoras/publicadas/`.
