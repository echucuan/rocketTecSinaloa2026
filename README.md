# Rocket Tec Sinaloa 2026

Portada del reto F1025B para pantalla de laboratorio de 75 pulgadas, preferentemente 16:9. Incluye los grupos 501, 502, 503 y 504. Adaptable a móvil.

## Vista previa

Abre `index.html` en Edge o Chrome. Mueve el ratón para mostrar el botón de pantalla completa; también puedes usar F11. El botón se oculta al dejar de mover el ratón. Para la TV usa resolución 1920 × 1080 o 3840 × 2160, zoom del navegador al 100 % y modo de imagen sin overscan (Ajustar a pantalla / Just Scan).

## Publicar en GitHub Pages

1. Descomprime el paquete.
2. En `echucuan/rocketTecSinaloa2026`, sube el CONTENIDO de esta carpeta: index.html, styles.css, identity.css, app.js, config.js, README.md y la carpeta assets completa. index.html debe quedar en la raíz del repositorio.
3. Guarda los archivos en la rama main.
4. En Settings → Pages, elige Deploy from a branch, rama main y carpeta /(root). Guarda.
5. Cuando GitHub termine el despliegue, la dirección prevista es https://echucuan.github.io/rocketTecSinaloa2026/

No subas el ZIP como un único archivo. No se requieren npm ni compilación.

## Actualizar el mensaje

Edita `config.js`: `etiqueta` cambia el encabezado del mensaje y `mensaje` cambia su texto. Usa `\n` para un salto de línea. Mantén el texto breve (dos líneas) para conservar el equilibrio en televisión. La portada no muestra fechas ni resultados sin confirmar.

## Recursos

Versión actualizada con los paquetes RocketTec.rar e IdentidadTecMty.rar proporcionados por el profesor. El encabezado utiliza el logotipo primario blanco del Tecnológico de Monterrey, intacto; la mención Campus Sinaloa aparece en un bloque separado. El emblema RocketTec original se presenta sin filtros, sombras ni elementos sobrepuestos. Se conserva espacio libre alrededor de ambos logotipos.

Paleta RocketTec: azul profundo #072F70, azul impulso #0751B5, azul cielo #469AFF y blanco. Tipografía de títulos: Bahnschrift instalada en Windows, con alternativas locales; textos de apoyo: Arial. No se redistribuyen las fuentes comerciales del Tec. Las fuentes libres del primer diseño permanecen como recursos de la hoja base, pero la hoja identity.css aplica la tipografía indicada por RocketTec. Todos los recursos son locales; no hay seguimiento ni servicios externos.
